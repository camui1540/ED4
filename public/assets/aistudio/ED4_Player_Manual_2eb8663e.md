# Earthdawn 4E 战术辅助面板 — 玩家使用说明书与 VTT 联机路线

## 第一部分：玩家与主持人（GM）使用说明书

### 1. 建卡与一键导入
- **手动微调**：在「角色卡（PL）」顶部选择**种族、门类（15 门类）、环数（1–15）**与**业力骰（D6/D8）**，系统会自动重算耐久血量上限、业力上限以及各环解锁的防御、先攻、回复与秘法护甲加值。
- **一键导入角色卡**：点击顶部**「导入角色卡 (.xlsx / .txt)」**，可直接上传填好的自动表 Excel 或 TXT 角色记录表。导入器会自动识别插行和列变化，读取属性、天赋（含负荷）、技能、武器、装备、脉路物品、传说点数、财富以及法术。

### 2. 日常检定与战斗操作
- **属性与常用检定**：点击属性卡片上的 `Step X` 按钮可直接掷骰；「常用检定」区支持一键投先攻、回复检定（自动扣次数并回血）、击倒检定（自动计入负伤平衡）、察觉、星界感知、意志抵抗与跃起。
- **天赋与技能并列面板**：左侧为门类天赋（可勾选业力骰），右侧为角色技能（不可使用业力），均支持顶部关键词筛选与独立滚动。
- **战斗选项与状态**：点击胶囊按钮可切换「猛烈攻击」「防御姿态」「击倒/震慑攻击」「分散移动」及「倒地/盲区/惊愕/受扰」。系统严格隔离动作检定与效果检定：负伤与状态减值只扣动作，不扣武器伤害。
- **装备与脉路物品穿脱**：每行最左侧的复选框控制该物品是否计入面板数值。首次导入默认已勾选并对齐卡面总值；之后取消勾选即可“脱下”装备并自动扣减对应护甲/防御/属性，重新勾选或新增带加值词条的物品会自动重算。

### 3. 施法者法术矩阵与拖拽
- **添加法术**：下拉框默认只显示**当前门类且不超过当前环数**的法术；如需跨门类选取，勾选旁边的「显示全部」。
- **拖拽换位**：直接按住法术卡片上的 `⠿` 图标，可在**★ 常备法术矩阵**与下方**法术书**之间来回拖放；把法术书里的卡片直接拖到某张常备卡片上即可互相替换。
- **施法流程**：需脉路的法术在织满前会锁定「施法」按钮，先点**「编织」**直到脉路数达标，再点**「施法」**对抗目标秘法防御（若场上有多只怪物，可在「当前目标」下拉框选择**群体目标：全场存活怪物**自动取最高秘防）；带动态伤害/效果骰的法术命中后，点击**「结算效果」**自动扣减护甲并结算伤害。

### 4. GM 面板、先攻与战报
- 在「怪物面板（GM）」可创建或删除 14 项全中文怪物模板，点击「加入战斗」或「批量生成 ×3」。
- 右侧边栏支持「全员投先攻」、轮次推进与「全队休整」；攻防命中会弹出待确认反应条（回避打击 / 反击）；战报中单次爆骰以**橙色**高亮，连续多次爆骰以**红色**高亮；开启顶部**「GM脱敏显示」**可向玩家隐藏敌方精确血量与抗性。

## 第二部分：完成第三阶段 VTT 联机还需要做什么？

目前面板是纯本地单机版（所有数据存在当前浏览器标签页内存里）。要升级为多人联机 VTT，需按以下 4 步推进：

1. **接入实时同步后端（推荐 Supabase）**
   - 建立房间表（`rooms`）、角色状态表（`characters`）与战报流水表（`combat_logs`）。
   - 使用 **Supabase Realtime**（Broadcast / Postgres Changes）替代单机内存变更：任何玩家掷骰、扣血、移动 Token 或推进先攻轮次时，状态实时广播给同房间所有成员。
2. **多角色数据隔离与 GM/PL 权限分流**
   - 将目前的单一 `state.pl` 拆分为房间内多个玩家各自持有的角色档案，并增加简单的房间口令或登录鉴权。
   - **真正实现端到端 GM 脱敏**：单机版的「GM脱敏显示」只是前端隐藏显示；联机版需由后端或房主通道控制，确保怪物精确血量/防御数据不直接下发到 PL 客户端，只下发脱敏后的状态描述。
3. **2D Canvas 空间化战术地图**
   - 在左侧主工作区增加「战术地图」页签，使用 HTML5 `<canvas>` 绘制网格标尺（码/米换算）、拖拽 Token、普通移速/全力移动范围圈、视线遮挡与战争迷雾。
   - 实现地图 Token 与先攻列表、怪物血条、目标选择的双向联动（点击地图上的怪物 Token 直接设为当前攻击目标）。
4. **静态资源与地图底图托管（Cloudflare R2）**
   - 如果需要上传自定义战斗地图底图或角色头像，可接入对象存储（如 Cloudflare R2）生成直链，避免把大体积图片直接塞进数据库。
